---------------

1) BACKUP CURRENT SOURCE
------------------------

cd C:\projects\basmat-facilities-cmms

2) EXTRACT SPRINT 2 ZIP
-----------------------
If the ZIP is in Downloads:

Expand-Archive `
-Path "$env:USERPROFILE\Downloads\basmat-facilities-cmms-sprint-2.zip" `
-DestinationPath "C:\projects\basmat-facilities-cmms" `
-Force

3) DEPENDENCIES
---------------
cd C:\projects\basmat-facilities-cmms
npm install
npm install @supabase/supabase-js react-router-dom

4) VERIFY .env.local
--------------------
It must already contain:

VITE_SUPABASE_URL=https://pxbtwjuerndgmppicumr.supabase.co
VITE_SUPABASE_ANON_KEY=<YOUR PUBLISHABLE KEY>

Never put service_role in the frontend.

5) RUN DATABASE SQL
-------------------
Supabase > SQL Editor > New Query

Open:
sql\SPRINT2_AUTH_RLS.sql

Run the whole script.

6) CREATE FIRST ADMIN USER
--------------------------
Supabase:
Authentication > Users > Add user

Create your admin email/password.

The trigger will create bf_profiles automatically.

Then in SQL Editor run:

update public.bf_profiles
set is_super_admin = true, status='active'
where email = 'PUT_YOUR_ADMIN_EMAIL_HERE';

Check:

select id,email,full_name,is_super_admin,status
from public.bf_profiles
order by created_at desc;

The admin row must show:
is_super_admin = true
